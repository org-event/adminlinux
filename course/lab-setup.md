# Лабораторное окружение

## Зачем

Все задания курса меняют состояние системы. Практикуйте **только** на учебном стенде.

## Минимальные требования к хосту

| Ресурс | Минимум | Рекомендуется |
|--------|---------|---------------|
| CPU | 2 ядра + VT-x/AMD-V | 4+ ядра |
| RAM | 6 ГБ свободных (metrics на `cli`) | 10+ ГБ |
| Диск | 50 ГБ свободно | 100+ ГБ SSD |
| Сеть | NAT к интернету | NAT + host-only / internal |

## Рекомендуемая топология

```text
                    ┌──────────────────┐
                    │  Host (гипервизор)│
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              │ NAT          │ host-only    │
         ┌────▼────┐    ┌────▼────┐
         │   srv   │    │   cli   │
         │ сервер  │◄──►│ клиент  │
         └─────────┘    └─────────┘
```

| ВМ | Роль | vCPU | RAM | Диск |
|----|------|------|-----|------|
| `srv` | основной сервер (службы, бэкап-источник) | 2 | 2–3 ГБ | 20 ГБ (+ второй диск 5–10 ГБ с модуля 05) |
| `cli` | внешние проверки, DR-target, Prometheus lite (модуль 14) | 1–2 | 1.5–2 ГБ | 15 ГБ |

**Mid+:** две ВМ обязательны с модуля 07 (раньше — желательно). С модуля 11 `cli` — off-host target бэкапа; с 14 — узел метрик.

## Выбор дистрибутива

Выберите **одну** основную семью и придерживайтесь её до капстоуна. В лабораториях команды даны для обеих семей, где они расходятся.

| Семья | Дистрибутив | Пакетный менеджер | Firewall |
|-------|-------------|-------------------|----------|
| Debian | Debian 12 / Ubuntu 22.04+ | `apt` | `nftables` / `ufw` |
| RHEL | Rocky 9 / AlmaLinux 9 | `dnf` | `firewalld` |

## Первичная настройка `srv`

1. Установите систему с SSH-сервером.
2. Задайте понятный hostname:

```bash
sudo hostnamectl set-hostname srv.lab.local
```

3. Создайте обычного пользователя с `sudo` (не работайте постоянно под root).
4. Обновите систему:

```bash
# Debian/Ubuntu
sudo apt update && sudo apt -y upgrade

# Rocky/Alma
sudo dnf -y update
```

5. Сделайте **снимок** «clean-base».
6. Запишите IP в `~/lab-notes/inventory.md`.

## Снимки — обязательная привычка

Делайте снимок:

- после чистой установки;
- перед модулями 05, 07, 08, 10, 11, 13, 14, 15, 12;
- перед любым экспериментом с `sshd`, firewall, LVM.

## Проверка готовности стенда

```bash
whoami
hostnamectl
ip -br a
cat /etc/os-release
df -h
```

Ожидание: вы вошли не как root (или понимаете риск), hostname задан, есть IP, диск не заполнен на 100%.

## Чего делать нельзя

- Практиковать на рабочем ноутбуке/проде «потому что быстрее».
- Отключать firewall «навсегда» без записи в заметках.
- Оставлять SELinux Permissive / AppArmor disabled как «решение» (см. модуль 13).
- Хранить учебные пароли в публичных репозиториях.
