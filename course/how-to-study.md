# Как учиться (планка middle+)

## Кому курс

Ожидается: уверенный базовый CLI, понимание «файл / процесс / сеть», готовность читать man и логи.  
Модули 01–04 — **сжатый mid bootstrap**, не развлекательные дриллы «поговорим о Linux».

Если команда `ls` / `cd` / `sudo` ещё вызывают паузу — сначала закройте пробел вне курса, иначе mid+ лаборатории будут мучительны без пользы.

## Принцип

Не читайте модуль «глазами до конца». Идите так:

1. **Inspect** — соберите факты (`ss`, `systemctl`, `journalctl`, `getenforce`/`aa-status`, метрики).
2. **Change** — одно осмысленное изменение за раз.
3. **Verify** — подтвердите фактами + негативным тестом (отказ доступа, падение алерта, check mode).
4. **Document** — что сделали, как откатить, какой риск остался.
5. **Automate** — повтор → скрипт / unit / timer / Ansible (с модуля 15 — IaC must в капстоуне).

Привычка оператора важнее запоминания флагов.

## Правила лаборатории

- Работайте **только** в ВМ / контейнере / выделенном стенде.
- Перед рискованными шагами — **снимок** гипервизора.
- Dual-distro: выполняйте ветку своей семьи; соседнюю читайте для переноса навыка.
- Критерии приёмки в `lab.md` — «экзамен без преподавателя».
- MAC (модуль 13): **не** оставляйте `setenforce 0` / полный disable AppArmor «навсегда».
- Observability (14): bash health-check — мост, не потолок; нужны метрики и алерты.
- Эшелон 16–20: практичные стенды (LDAP lite, HA lite, k3s/kind), не enterprise/CKA.
- Капстоун (12): TLS, metrics/alerts, Ansible, DR drill, postmortem — **must**; плюс ≥1 усиление из HA / identity / containers.

## Порядок

```text
01→11 → 13→15 → 16→20 → 12
```

Не перескакивайте 07→10→12: службы, MAC и IaC опираются на сеть, права и журналы.  
Эшелон 16–20 после 15: иначе капстоун и зависимости (SSSD, k8s, VIP) будут хрупкими.

## Темп

| Режим | Ритм |
|-------|------|
| Интенсив | 1 модуль / день (bootstrap); 1–2 дня на 10/11/13–15; 1–2 дня на 16–20 |
| Рабочий | 2–3 модуля / неделя на A–C; по модулю на D–F |
| Глубокий | модуль + повтор инцидентов / alert drill / restore / failover |

## Артефакты

В домашнем каталоге на `srv` заведите `~/lab-notes/`:

```text
~/lab-notes/
  01.md … 20.md, 12.md   # факты, команды, грабли, RPO/RTO
  inventory.md           # IP, hostname, роли, дистрибутив
  credentials.md         # только учебные пароли стенда
  HANDOFF.md             # финал капстоуна
  12-postmortem.md       # разбор инцидента капстоуна
```

На капстоуне заметки превращаются в handoff + evidence pack + postmortem.
