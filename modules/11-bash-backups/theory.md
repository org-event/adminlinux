# Теория — скрипты и бэкапы

## Минимальный каркас bash для админа

```bash
#!/usr/bin/env bash
set -euo pipefail

log() { echo "$(date -Is) $*"; }

main() {
  log "start"
  # ...
  log "done"
}

main "$@"
```

- `set -e` — выход при ошибке
- `set -u` — ошибка на неопределённых переменных
- `set -o pipefail` — ошибка в пайпе не теряется

## rsync

```bash
rsync -aHAX --delete /src/ /dst/
rsync -a /etc/nginx/ /backup/nginx/
```

Для учебных бэкапов часто достаточно копий конфигов + данных приложения.

## Политика бэкапа (простая)

1. Что копируем (конфиги, `/srv`, список пакетов).
2. Куда (отдельный каталог/том, не тот же единственный диск без копии).
3. Как часто (timer).
4. Как проверяем (код возврата, размер, тестовое восстановление файла).
5. Как долго храним (ротация каталогов по дате).

Бэкап без проверки восстановления — фикция.
