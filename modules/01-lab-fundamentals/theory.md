# Теория — окружение и основы

## Что такое Linux-сервер в работе админа

Сервер — это машина (физическая или виртуальная), где вы:

- управляете доступом людей и служб;
- ставите и обновляете ПО;
- следите за дисками, сетью, логами;
- восстанавливаете работу после сбоев.

Дистрибутив = ядро Linux + набор пользовательского ПО + политика обновлений. В курсе две семьи:

- **Debian/Ubuntu** — `apt`, юниты systemd, часто `nftables`/`ufw`;
- **RHEL/Rocky/Alma** — `dnf`, systemd, обычно `firewalld` + SELinux.

## Иерархия файловой системы (FHS)

| Путь | Назначение |
|------|------------|
| `/` | корень |
| `/etc` | конфигурация |
| `/var` | переменные данные, логи |
| `/home` | домашние каталоги пользователей |
| `/usr` | программы и библиотеки |
| `/tmp` | временные файлы |
| `/proc`, `/sys` | интерфейсы ядра (не «настоящие» файлы на диске) |

## Root и sudo

`root` — полный доступ. В учебной практике:

1. Войдите обычным пользователем.
2. Для админ-действий используйте `sudo`.
3. Проверяйте, что делаете: `sudo -l`.
