# Лаборатория 01 — окружение и основы

## Цель

Поднять ВМ `srv`, зафиксировать инвентарь и научиться собирать факты о системе.

## Окружение

- ВМ по [lab-setup](../../course/lab-setup.md)
- Каталог заметок `~/lab-notes/`
- Снимок `clean-base` после выполнения

## Задания

### 1. Inspect — паспорт системы

Соберите и сохраните в `~/lab-notes/01.md`:

```bash
mkdir -p ~/lab-notes
{
  echo "## Паспорт srv"
  date -Is
  cat /etc/os-release
  hostnamectl
  uname -r
  free -h
  df -hT
  lsblk
  ip -br a
} | tee ~/lab-notes/01-passport.txt
```

### 2. Change — hostname и заметки

1. Задайте hostname `srv.lab.local` (если ещё не задан).
2. Создайте `~/lab-notes/inventory.md` с полями: hostname, IP, дистрибутив, пользователь, дата снимка.

### 3. Verify — FHS и man

1. Покажите содержимое `/etc`, `/var/log`, `/home` (только список, без удаления).
2. Откройте `man hier` или `man 7 hier` (если доступен) либо кратко опишите назначение `/etc` и `/var` своими словами в заметках.
3. Найдите страницу man для `sudo` и выпишите один важный для вас флаг.

### 4. Document

В `~/lab-notes/01.md` ответьте:

- Чем ваш дистрибутив отличается от «просто Linux»?
- Почему практикуем не на хосте разработчика?

## Критерии приёмки

- [ ] Есть файл паспорта системы с os-release, RAM, дисками, IP
- [ ] Hostname = `srv.lab.local` (`hostnamectl`)
- [ ] Существует `~/lab-notes/inventory.md`
- [ ] Сделан снимок `clean-base`
- [ ] В заметках есть ответы из задания Document

## Подсказки

- Если `hostnamectl` недоступен — это редкость; проверьте, что используете systemd-дистрибутив.
- IP смотрите через `ip -br a`, не через устаревший `ifconfig`, если его нет в системе.

## Очистка

Ничего откатывать не нужно. Сохраните снимок.
