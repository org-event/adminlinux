# Лаборатория 01 — инвентарь стенда

## Цель

Поднимите `srv`, сдайте паспорт и inventory так, чтобы не осталось вопроса «на какой машине я работаю».

## Окружение

- ВМ по [lab-setup](../../course/lab-setup.md)
- Каталог `~/lab-notes/`, в конце — снимок `clean-base`

## Задания

### 1. Осмотр — паспорт

```bash
mkdir -p ~/lab-notes/bin
{
  echo "## passport srv"; date -Is
  cat /etc/os-release; hostnamectl; uname -r
  free -h; df -hT; lsblk; ip -br a; id
  systemctl is-system-running || true
} | tee ~/lab-notes/01-passport.txt
```

### 2. Изменение — идентичность

1. Hostname `srv.lab.local`.
2. В `~/lab-notes/inventory.md` укажите: hostname, IP (NAT + lab), семья дистрибутива, пользователь, hypervisor, дату снимка, план второй ВМ `cli`.

### 3. Проверка — две семьи дистрибутивов

В `~/lab-notes/01.md` сделайте таблицу (5–7 строк): пакеты / firewall / MAC / типичный путь к логам / «как обновить систему» — для **вашей** семьи и кратко для **другой**.

Проверьте пакетный менеджер (лишнее не ставьте):

| Семья | Команда |
|-------|---------|
| Debian/Ubuntu | `sudo apt update` |
| Rocky/Alma | `sudo dnf repolist` |

### 4. Проверка — негатив «не тот хост»

В `01.md` напишите чеклист из ≥4 пунктов (hostname, IP/интерфейсы, нет личных данных в `/home`, снимок/метка ВМ). Пройдите его и отметьте результат.

### 5. Автоматизация

`~/lab-notes/bin/collect-passport.sh` — заново собирает `01-passport.txt` (timestamp обновляется). Запустите два раза подряд и сохраните оба вывода в `~/lab-notes/`.

### 6. Запись

В `01.md`: что войдёт в снимок `clean-base`; зачем вторая ВМ на mid+ (проверка снаружи, DR-target, metrics).

## Критерии приёмки

- [ ] Паспорт с os-release, RAM, дисками, IP, состоянием systemd
- [ ] Hostname `srv.lab.local`, актуальный `inventory.md`
- [ ] Таблица по двум семьям заполнена
- [ ] Негатив «не тот хост» выполнен
- [ ] Скрипт паспорта + снимок `clean-base`

## Подсказки

- IP берите из `ip -br a`. На `ifconfig` не опирайтесь.
- Если не вышло с интернетом — почините NAT/DNS до модуля 04.

## Очистка

Откатывать нечего. Сохраните снимок.
