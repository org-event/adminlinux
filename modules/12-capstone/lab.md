# Лаборатория 12 — капстоун

## Цель

Привести `srv` к воспроизводимому состоянию «учебный прод» и сдать handoff.

## Окружение

- Чистый снимок **или** приведённый в порядок стенд после модулей 01–11
- ВМ `cli` для внешних проверок
- Снимок `capstone-final` в конце

## Задание (единый сценарий)

Разверните и опишите сервер со следующими свойствами:

### Обязательный объём

1. **Идентичность:** hostname, актуальный inventory.
2. **Доступ:** вход по SSH-ключу, root login запрещён, парольный SSH выключен.
3. **Пользователи:** минимум две роли (например admin-оператор и пользователь данных/группы opslab).
4. **Хранилище:** отдельный том под данные (LVM), автомонтирование.
5. **Firewall:** разрешены только нужные порты/сервисы.
6. **HTTP:** nginx отдаёт страницу статуса (hostname, дата, версия ОС).
7. **Обмен:** NFS-шара только в lab-сеть **или** осознанная замена с обоснованием в handoff.
8. **Наблюдаемость:** health-check по timer + понятные логи.
9. **Бэкап:** скрипт + timer + доказанное восстановление одного файла.
10. **Handoff:** документ `~/lab-notes/HANDOFF.md` (или `course-artifacts/HANDOFF.md` на хосте).

### Дополнительно (на выбор, +балл себе)

- fail2ban для ssh
- отдельный HTTPS с самоподписанным сертификатом (с предупреждением)
- второй сайт/virtual host
- Ansible-плейбук «настроить с нуля» (если уже умеете — не обязательно в базовом курсе)

## Порядок работы

1. Inspect текущего состояния — составьте gap-list относительно обязательного объёма.
2. Change — закройте пробелы по одному, с verify после каждого.
3. Прогоните внешние проверки с `cli`.
4. Напишите HANDOFF.
5. Сделайте снимок `capstone-final`.

## Критерии приёмки (рубрика)

| Критерий | Вес | Доказательство |
|----------|-----|----------------|
| SSH hardened | must | негативный тест пароля + вход ключом |
| HTTP доступен с cli | must | `curl` вывод |
| Данные на LVM | must | `findmnt`, `lsblk` |
| Firewall минимален | must | list rules + обоснование |
| Health-check жив | must | log/timer |
| Backup + restore | must | заметка восстановления |
| HANDOFF полный | must | ответы на 7 вопросов теории |
| NFS или эквивалент | must | mount с cli или раздел «почему без NFS» |
| Чистота заметок | should | inventory актуален |

## Подсказки

- Не переписывайте всё с нуля без причины — доведите существующий стенд.
- Если что-то ломается, вернитесь к runbook модулей 07–08.
- Капстоун оценивает операторскую дисциплину сильнее, чем «красоту» конфигов.

## Очистка

Стенд сохраните. Это ваше портфолио-доказательство навыка.
