# Лаборатория 04 — пакеты и обновления

## Цель

Поставить набор админ-утилит, зафиксировать версии и научиться отвечать на вопрос «что это за пакет и откуда».

## Окружение

- ВМ `srv` с доступом в интернет (NAT)

## Задания

### 1. Inspect

```bash
# Debian
cat /etc/os-release
sudo apt update
apt list --upgradable | head

# RHEL
sudo dnf check-update | head
```

Запишите количество доступных обновлений (примерно) в заметки.

### 2. Change — установка набора

Установите: `tree`, `curl`, `jq`, `htop` (или `btop`, если есть в репозитории).

### 3. Verify — паспорт пакета

Для `curl` сохраните в `~/lab-notes/04-curl.txt`:

- описание пакета;
- версию;
- несколько файлов, которые он предоставляет;
- какой бинарь запускается (`command -v curl`).

### 4. Change — поиск и зависимости

Найдите пакет, который даёт команду `dig` (часто `dnsutils` или `bind-utils`), установите его и проверьте `dig example.com +short`.

### 5. Document

В `~/lab-notes/04.md` ответьте:

- Чем `apt update` отличается от `apt upgrade`?
- Почему опасны случайные сторонние RPM/DEB из чатов?

## Критерии приёмки

- [ ] Утилиты установлены и вызываются из PATH
- [ ] Есть паспорт пакета `curl`
- [ ] `dig` работает
- [ ] В заметках есть ответы Document

## Подсказки

| Команда | Debian | RHEL |
|---------|--------|------|
| обновить индексы | `apt update` | метаданные подтягивает `dnf` |
| пакет для dig | `dnsutils` | `bind-utils` |

## Очистка

Пакеты оставьте — пригодятся дальше.
