# Lab Format

## Purpose

Задаёт единый формат лабораторных работ и заданий курса: операторский цикл,
обязательные секции lab.md и проверяемые критерии приёмки без преподавателя.

## Requirements

### Requirement: Operator loop

Каждая лабораторная работа SHALL вести обучающегося по циклу: осмотр → изменение → проверка → документирование → (по возможности) автоматизация.

#### Scenario: Lab steps follow the loop

- **GIVEN** файл `lab.md` модуля
- **WHEN** обучающийся выполняет задания по порядку
- **THEN** сначала собирает факты (inspect), затем вносит изменения, затем проверяет результат командами/критериями

### Requirement: Lab sections

Каждый `lab.md` SHALL содержать секции: Цель, Окружение, Задания, Критерии приёмки, Подсказки, Очистка.

#### Scenario: Reviewer checks lab completeness

- **GIVEN** новая лабораторная работа
- **WHEN** проверяют готовность модуля
- **THEN** все обязательные секции присутствуют и критерии приёмки проверяемы

### Requirement: Acceptable evidence

Критерии приёмки SHALL опираться на наблюдаемые факты: вывод команд, состояние файлов, статус служб, сетевую доступность.

#### Scenario: Self-check without instructor

- **GIVEN** обучающийся завершил задания
- **WHEN** сверяется с критериями приёмки
- **THEN** может самостоятельно подтвердить успех по выводу команд и чеклисту
